# pg-logigate

**邏輯閘沙盒**：開關、NOT／AND／OR、LED 與接線的數位邏輯小品。純前端，無建置步驟。

僅供作為 [Playgrounds（遊樂場）](https://samkuo.me/playgrounds/) 範本小品。理想二值模型——**不是** HDL／EDA／時序驗證工具。

## 試玩（本機）

```bash
npx --yes serve .
```

- 左側選元件 → 點畫布放置  
- 點輸出腳 → 再點輸入腳接線  
- 點開關切換；Delete 刪選取  
- 內建「半加器」「AND 範例」
